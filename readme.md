# 🚗 Driving School Management System API

A **modern full-stack backend system** developed for the **Vajira Driving School**, built using **Node.js and MongoDB** as an **advanced upgrade of the existing PHP-based Driving School Management System**.

This system enables students to **book driving lessons online**, while administrators can **manage students, instructors, bookings, and payments** through a scalable API.

# 📌 Features

## 🔐 Authentication & Access Control

- JWT-based authentication system
- Secure password hashing (bcrypt)
- Role-based access control: Admin / Instructor / Student
- Protected API routes

## 👨‍🎓 Student Management

- Student registration and profile management
- Store personal and contact details
- Track student status: Pending / Verified

## 🧑‍🏫 Instructor Management

- Manage instructor profiles
- Define instructor availability
- Assign instructors to bookings

## 📅 Booking Management

- Book driving lessons online
- Prevent double booking conflicts
- Assign instructors automatically
- Track booking status: Booked / Completed / Cancelled

## 💳 Payment Management

- Record payments for bookings
- Track payment status: Pending / Paid
- Maintain transaction history

## 📊 Reports & System Insights

- View booking history
- Track payments and revenue
- Monitor system activity

## 📈 Admin Control

- Manage students, instructors, and bookings
- Control system operations via API
- Centralized data management

## ⏰ Automation & Notifications

- Lesson reminders using cron jobs
- Email notifications for bookings
- Automated system updates

## 🛡 Backend Architecture

- MVC + Service Layer architecture
- Middleware-based error handling
- Input validation and security
- Scalable and modular codebase

## 🔄 Upgrade from Existing System

- Migrated from PHP → Node.js
- Upgraded MySQL → MongoDB
- Introduced REST API architecture
- Improved scalability and performance
- Better code organization and maintainability
